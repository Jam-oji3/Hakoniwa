# 2Dエディタ仕様

本書は、Piece-first編集で使用する2Dエディタの表示範囲、29×29プレート配置、座標変換、ビュー操作を定義する。

## 1. 基本方針

- 2Dエディタは、選択中のPieceをそのローカル平面へ投影して表示・編集する。
- 29×29マスの四角プレートを表示上の基準単位とする。ただし、Pieceの大きさを29×29へ制限しない。
- プレート配置はPieceのBead座標から導出するPresentation上の一時状態とする。Domainおよび`.ibcad`には、プレート枚数や表示範囲を保存しない。
- Beadの追加、削除、色変更はApplication Commandとして実行し、Undo／Redoの対象とする。

## 2. Piece平面と2D座標

Pieceの平面に応じ、3D格子座標を次の2D座標 `(u, v)` へ投影する。

| Piece平面 | `u` | `v` | 固定座標 |
| --- | --- | --- | --- |
| XY | `x` | `y` | `z` |
| XZ | `x` | `z` | `y` |
| YZ | `y` | `z` | `x` |

画面座標と2D格子座標の変換は、描画とポインターのヒットテストで同じ変換を使用する。Pieceの単一平面制約はDomainで検証する。

## 3. 空のPieceの初期表示

- Beadを持たないPieceを選択した場合、原点を中央セルとする29×29プレートを1枚表示する。
- 初期プレートの2D座標範囲は、両軸とも `-14..=14` とする。
- プレート外側は空白または通常より薄い補助グリッドとして描画する。編集可能な領域自体はプレート内に限定しない。

## 4. 既存Pieceの初期プレート配置

Beadを持つPieceを選択した場合、全Beadを覆う最小枚数の29×29プレートを長方形に配置する。

1. 全Beadを2D座標へ投影し、`min_u`、`max_u`、`min_v`、`max_v`を求める。
2. 先頭プレートの原点を `(min_u, min_v)` とする。
3. 必要枚数を次式で求める。
   - 横: `ceil((max_u - min_u + 1) / 29)`
   - 縦: `ceil((max_v - min_v + 1) / 29)`
4. 求めた横枚数×縦枚数の長方形領域を、隙間なく連結して表示する。

グローバル原点を基準に29マスごとへ固定すると、小さなPieceでも境界をまたいで余分なプレートが必要になるため、既存Pieceの初期原点はそのPieceの最小座標へ合わせる。

## 5. プレート外への編集と拡張

- 現在のプレート外にも格子座標を割り当て、Beadを配置できるようにする。
- プレート外のセルへBeadを配置した時点で、そのセルを含むように29×29プレートを追加する。
- 追加後のプレート領域は常に既存領域と辺で連結した長方形とする。離れたセルへ配置した場合は、既存領域との間に必要なプレートも追加する。
- 拡張は29マス単位で行い、既存のプレート境界と格子座標を維持する。
- 左側または下側へ拡張してプレート原点が変わっても、画面上の既存Bead位置が跳ねないよう、同量だけビューのパン位置を補正する。
- 外側の補助グリッドは通常のセル線より薄く表示し、Bead配置後は追加された29×29領域を通常の濃さへ切り替える。
- 低ズーム時または描画負荷が高い場合は、外側の補助グリッドを省略して空白にしてよい。ただし、ポインター位置のセル候補は判別できる表示を行う。

## 6. 削除、Undo／Redo、再選択

- 編集中に追加プレート内のBeadがすべて削除されても、プレート領域を自動では縮小しない。編集中の座標系と画面位置を安定させるためである。
- Bead配置をUndoした場合も、同じ編集セッション中はプレート領域を維持する。
- Pieceを選択し直した場合は、現在のBead範囲から第4節の規則で最小枚数を再計算する。
- Beadがすべて削除された状態で選択し直した場合は、第3節の原点中心29×29プレートへ戻す。

## 7. ビュー操作

| 操作 | 挙動 |
| --- | --- |
| 中ホイールドラッグ | 2Dビューを平行移動する |
| Shift＋中ホイールドラッグ | 平行移動する（Shiftなしと同じ） |
| ホイール回転 | ポインター位置を基準にズームする |

- ズームしても、ポインター下の格子座標が可能な限り同じ画面位置に残るようパン量を補正する。
- パンおよびズームはPresentation上のビュー状態であり、Undo／Redoや`.ibcad`保存の対象外とする。

## 8. 表示

- 29×29プレートの外周線は、通常のセル境界より強く表示する。
- 隣接プレート間の境界は、格子の連続性を保ちながらプレートの接続位置を識別できる表示にする。
- Bead、通常グリッド、プレート境界、外側補助グリッドの順に視認性の差を設ける。
- 選択中Pieceの名前、平面、プレート枚数、図案のセル寸法を確認できるようにする。

## 9. 確認項目

- [x] 空のPieceで `-14..=14` の29×29プレートが1枚表示される。
- [x] 既存Pieceを選択すると、全Beadを覆う最小枚数のプレートが表示される。
- [x] 29マス以内のPieceは、座標がグローバルな29マス境界をまたいでも1枚で表示される。
- [x] プレート外への配置で、対象セルまで連結したプレートが29マス単位で追加される。
- [x] 左・下方向へ拡張しても、既存Beadの画面位置が跳ねない。
- [x] 削除およびUndoで編集中のプレート配置が不意に縮小しない。
- [x] Pieceを選択し直すと、現状態に対する最小枚数へ再計算される。
- [x] 中ホイールドラッグによるパンと、ポインター基準のホイールズームが動作する。
- [x] XY、XZ、YZの各Pieceで描画位置と編集位置が一致する。
